# 중국 출장 검색 & 번역 도우미 🇨🇳

중국 출장 중 한글 또는 영어로 검색하고, 자동으로 중국어로 번역하여 중국 주요 사이트에서 검색 결과를 확인할 수 있는 웹 애플리케이션입니다. 실시간 대화 번역 기능으로 현지에서 바로 사용할 수 있습니다.

## 주요 기능

### 🔍 검색 & 번역
- ✅ **자동 번역**: 한글/영어 검색어를 중국어로 자동 번역
- 🌐 **다중 사이트 검색**: Baidu, Dianping, Taobao, JD.com, Weibo, Zhihu 등 주요 중국 사이트 지원
- 🎨 **직관적인 UI**: 깔끔하고 사용하기 쉬운 인터페이스

### 💬 실시간 대화 번역기
- 🗣️ **즉시 번역**: 한글 문장을 중국어로 실시간 번역
- 📋 **클립보드 복사**: 번역 결과를 빠르게 복사
- 🔊 **음성 읽기**: 중국어 발음을 음성으로 재생
- 📝 **번역 히스토리**: 이전 번역 내용을 저장하고 재사용
- ⚡ **자주 쓰는 문구**: 12개의 프리셋 문구 제공
  - "지금 가도 되나요?" → "现在可以去吗?"
  - "얼마인가요?" → "多少钱?"
  - "주소를 알려주세요" → "请告诉我地址"
  - "어떻게 가나요?" → "怎么去?"
  - "추천해주세요" → "请推荐"
  - "메뉴판 주세요" → "请给我菜单"
  - "계산해주세요" → "买单"
  - "포장 가능한가요?" → "可以打包吗?"
  - "예약하고 싶습니다" → "我想预订"
  - "화장실이 어디인가요?" → "洗手间在哪里?"
  - "도와주세요" → "请帮我"
  - "감사합니다" → "谢谢"

### 📱 스마트 앱 연동
- **딥링크 지원**: 모바일에서 앱이 설치되어 있으면 자동으로 앱으로 열기
- **3가지 선택 옵션**: 
  - 📱 앱으로 열기 (앱이 설치되어 있을 때)
  - 🌐 웹으로 보기 (브라우저에서 열기)
  - 📲 앱 다운로드 (App Store/Google Play로 이동)
- **자동 디바이스 감지**: 모바일/데스크톱 자동 인식
- **플랫폼 구분**: iOS/Android 각각에 맞는 스토어 링크 제공

### 💻 기타 기능
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원
- **3개 탭 구조**: 검색&번역, 대화번역기, 검색결과
- **애니메이션 모달**: 부드러운 사용자 경험

## 지원 사이트

1. **Baidu (百度)** - 중국 최대 검색 엔진
2. **Dianping (大众点评)** - 맛집 & 리뷰 플랫폼 (중국의 옐프)
3. **Taobao (淘宝)** - 중국 최대 쇼핑몰
4. **JD.com (京东)** - 중국 전자상거래 플랫폼
5. **Weibo (微博)** - 중국 소셜 미디어
6. **Zhihu (知乎)** - 중국 지식 커뮤니티

## 기술 스택

- **Frontend**: React 18 + Vite
- **Backend**: Node.js + Express
- **API**: Google Translate API (무료)
- **Styling**: CSS3 (반응형 디자인)
- **Speech**: Web Speech API (TTS)

## 설치 및 실행

### 1. 의존성 설치
```bash
npm install
```

### 2. 백엔드 서버 실행
```bash
npm run server
```
서버가 `http://localhost:3001` 에서 실행됩니다.

### 3. 프론트엔드 개발 서버 실행 (새 터미널)
```bash
npm run dev
```
애플리케이션이 `http://localhost:3000` 에서 실행됩니다.

## 사용 방법

### 검색 & 번역 탭
1. 검색창에 한글 또는 영어로 검색어 입력 (예: "스마트폰", "smartphone")
2. "중국어로 번역" 버튼 클릭
3. 번역된 중국어 검색어 확인
4. "중국 사이트에서 검색" 버튼 클릭
5. 원하는 중국 사이트 버튼을 클릭
   - **모바일**: 앱/웹/다운로드 선택 모달이 나타남
     - 📱 "앱으로 열기" - 앱이 설치되어 있으면 바로 실행
     - 🌐 "웹으로 보기" - 브라우저에서 열기
     - 📲 "앱 다운로드" - App Store 또는 Google Play로 이동
   - **데스크톱**: 자동으로 웹 브라우저로 열림

### 대화 번역기 탭
1. 번역할 문장 입력하고 🔄 버튼 클릭 (또는 Enter)
2. 번역된 중국어 확인
3. 📋 복사 버튼으로 클립보드에 복사
4. 🔊 읽기 버튼으로 중국어 발음 듣기
5. 자주 쓰는 문구 버튼으로 빠른 번역
6. 번역 히스토리에서 이전 번역 재사용

## API 엔드포인트

### POST /api/translate
한글/영어를 중국어로 번역
```json
{
  "text": "스마트폰",
  "sourceLang": "auto",
  "targetLang": "zh"
}
```

**응답:**
```json
{
  "originalText": "스마트폰",
  "translatedText": "智能手机",
  "sourceLang": "auto",
  "targetLang": "zh"
}
```

### POST /api/search
중국 주요 사이트 검색 URL 생성
```json
{
  "query": "智能手机"
}
```

**응답:**
```json
{
  "query": "智能手机",
  "searchUrls": {
    "baidu": "https://www.baidu.com/s?wd=智能手机",
    "dianping": "https://www.dianping.com/search/keyword/2/0_智能手机",
    "taobao": "https://s.taobao.com/search?q=智能手机",
    "jd": "https://search.jd.com/Search?keyword=智能手机",
    "weibo": "https://s.weibo.com/weibo?q=智能手机",
    "zhihu": "https://www.zhihu.com/search?type=content&q=智能手机"
  }
}
```

### POST /api/translate-back
중국어를 한글/영어로 역번역
```json
{
  "text": "智能手机",
  "targetLang": "ko"
}
```

## 주의사항

- 백엔드 서버(포트 3001)와 프론트엔드(포트 3000)를 모두 실행해야 합니다.
- 중국 사이트 접속을 위해 VPN이 필요할 수 있습니다.
- Google Translate API는 무료 버전을 사용하며, 대량 요청 시 제한될 수 있습니다.
- 음성 읽기 기능은 브라우저의 Web Speech API를 사용합니다. (Chrome, Edge 권장)

## 사용 팁

1. **대화 번역기 활용**: 레스토랑, 택시, 호텔 등에서 자주 쓰는 문구를 미리 번역해두세요.
2. **음성 읽기**: 발음이 어려운 경우 🔊 버튼으로 중국어 발음을 들려주세요.
3. **히스토리 관리**: 자주 사용하는 문구는 히스토리에서 빠르게 재사용할 수 있습니다.
4. **Dianping 활용**: 맛집을 찾을 때는 Dianping에서 리뷰와 평점을 확인하세요.
5. **앱 다운로드**: 중국 출장 전에 주요 앱들을 미리 다운로드해두면 편리합니다.
   - Baidu - 검색 및 지도
   - Dianping - 맛집 리뷰
   - Taobao/JD - 쇼핑
   - Weibo - SNS
   - Zhihu - 정보 검색
6. **모바일에서 사용**: 이동 중에는 스마트폰에서 접속하여 바로 앱으로 연결하세요.
